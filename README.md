# Lock Out Villa Bookings

Build a fully responsive, dynamic resort booking website for “Lock Out Villa.” Enable Lovable Cloud first for accounts, bookings, availability, admin data, and image uploads. Include pages/navigation: Home, Photos, Contact, Booking. Present accommodations: Room 1–4 (each 4 guests), Tent 1–2 (each 4 guests), Hall 1 for up to 16 guests, Hall 2 for up to 10 guests, plus garden, children’s park, and swimming pool. Create an attractive resort-style design with appropriate placeholder imagery, gallery, amenities, rates and availability views; make it easy to replace/add resort images. Guests must sign up/log in before submitting booking requests. Create an admin-only login flow where username ad7979 and password 999 redirects to an admin dashboard. The dashboard should show booking request counts, room availability, and let admin manage accommodation prices, availability, and resort images. Include booking-request contact details/actions so admin can call/contact guests who request bookings. Do not expose the admin password anywhere in the public UI.
